# Pinch landing page

A static landing page for **Pinch**, a tiny task tracker for small teams. Plain HTML, CSS and JavaScript, with no framework and no build step.

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
```

Features: animated kanban hero, features grid, how-it-works steps, testimonials carousel, pricing with a monthly/yearly toggle, FAQ, email signup, and a light/dark theme toggle.

- `SPEC.md`: the shared contract for markup, behaviour and styling
- `RESEARCH.md`: background research
- `REVIEW.md`: test results
